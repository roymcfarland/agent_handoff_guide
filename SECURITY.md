# Security policy

## Report a vulnerability

Report vulnerabilities privately through GitHub. Open the repository’s **Security** tab and choose [**Report a vulnerability**](https://github.com/roymcfarland/agent_handoff_guide/security/advisories/new).

Include the affected version or commit, the affected feature, what you observed, the impact, and steps to reproduce using test data. Omit credentials and personal data.

Keep vulnerability details out of public issues and pull requests. If the private form is unavailable, open a public issue that says only that you have a security report and asks for a private channel.
